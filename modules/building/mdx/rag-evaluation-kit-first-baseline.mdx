I wanted a test small enough to run after every meaningful retrieval change. The first version uses 24 questions that cover clear answers, missing context, conflicting sources, and questions the system should decline to answer.

## What I learned

A small, carefully chosen set catches more useful problems than a large collection of vague examples. The report now shows which source supported an answer and where the system guessed beyond its context.
