Raw traces contain useful evidence, but they make the reader reconstruct the workflow by hand. The first TraceGarden view now groups each decision with the action it triggered and the observation that came back.

The timeline also separates expected tool failures from failures that stopped the run. That makes the useful question—“where did this attempt stop making progress?”—much easier to answer.
