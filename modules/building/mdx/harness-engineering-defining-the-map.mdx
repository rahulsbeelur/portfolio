“Harness engineering” can become a label for almost everything around an AI agent. I wanted a map small enough to use.

I am starting with four layers: the context the agent receives, the actions it can take, the observations it produces, and the evaluation that decides whether the result is useful. Each layer has different failure modes, so each needs a different kind of visibility.
