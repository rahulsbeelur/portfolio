The first pass was about reducing the idea to a loop I can see and test:

1. Give the agent a bounded task and explicit success conditions.
2. Capture the context it received and the actions it took.
3. Evaluate the result with a small, opinionated test set.
4. Feed the failure back into the next attempt.

The interesting part is not the model call. It is the harness around it—the part that turns one impressive attempt into a system that can improve.

## What changed today

I now have a trace shape for each attempt and a tiny set of checks that says more than “this feels right.” The next run will use a real repository task so I can see which missing context actually affects the result.
