The first SchemaGuard pass focuses on changes that are structurally easy to identify and operationally expensive to miss: removing a field, changing its type, or making an optional value required.

Each failure now includes a short explanation and a suggested migration sequence. The aim is to help the author fix the change, not simply reject the pull request.
